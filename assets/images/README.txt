IMAGE PLACEHOLDERS
===================

This folder is where you should add your own images. The code already has
labeled placeholders (search for "TODO" comments) pointing to these spots:

logo/
  - logo.png            Your company logo, shown in the sidebar brand area
                         (includes/sidebar.php) and in email headers if you
                         extend includes/mailer.php to use it.
  - favicon.png          Small icon for the browser tab (see the <head> in
                         includes/header.php).

avatars/
  - Employee/agent profile photos are uploaded automatically through
    profile.php and stored here — you don't need to add anything manually.

Suggested login page illustration:
  - Add an image at assets/images/login-illustration.png and uncomment the
    <img> tag near the top of login.php (auth-panel-brand section).

Recommended sizes: logo ~200x200px transparent PNG, favicon 32x32px or 64x64px.
